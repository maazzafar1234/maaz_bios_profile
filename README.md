## 🚀 Overview

**MAAZ_ZAFAR.SYS** is a modern developer portfolio designed with a nostalgic retro-computer aesthetic. The website simulates a BIOS boot sequence and CRT monitor experience while presenting professional information in an engaging and interactive way.

The portfolio includes:

- Interactive boot screen animation
- CRT and phosphor monitor effects
- Theme switching (Green ↔ Amber)
- Project flip cards with 3D interactions
- Animated skill progress bars
- Resume download section
- Contact form integration
- Responsive glassmorphism design
